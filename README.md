# OfflineChat

A fully offline AI chat application powered by local LLMs via node-llama-cpp.

## Features
- 💬 Chat with local AI models
- 📎 RAG support (PDF, images, text files)
- 📚 Chat history (SQLite)
- 🎨 Dark theme UI
- 🔌 Fully offline - no internet required
- 🖥️ Frameless window with custom title bar
